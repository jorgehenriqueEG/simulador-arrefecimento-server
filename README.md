# Simulador Arrefecimento Server
## Descrição do Problema
Simula a queda de temperatura de um servidor após o desligamento, considerando o fluxo de ar residual.
## Requisitos
* Receber temperatura inicial em Celsius
* Calcular a temperatura após 5 minutos
* Aplicar taxa de resfriamento de 2.5°C por minuto
## Exemplo de Uso
Entrada: 85.0
Saída: Temperatura final: 72.5°C
